# 修正清单（总说误信「官星有力」及其同源措辞）

对象：`甲子 乙亥 庚戌 癸未`（男）· 四版《三命通会》通读报告
范围：总说、五栏结论、逐运判断、封面与导语、原局各节说明

## 一、错在哪

总说第一句原为：

> 这一命的眼在「官星有力，位置拿得住」上：官与财都从时支的库里透出来，走的是先有手艺、后有位置这一路。

三处都不成立：

1. **官星只有藏、没有透**。本命官星是丁火，只在日支戌、时支未里各藏一个，天干一个丁也没有。
2. **官星还受制**。时干癸是伤官，癸克丁，藏着的官被明透的伤官压住，正是「伤官见官」。
3. **财不是从时支库透的**。财是甲乙两木，透在年干、月干；时支未里的乙只是余气，谈不上「从库透出」。

来源是日时断那首局歌里的「官旺財鄉」，它在条件校验时已判「不成立·仅备一说」，结论却漏进了总说。同源的措辞还漏进了五栏的禄、子、寿三栏。

## 五、第三轮同检（总说撞句、禄栏不接、九十块复述）

口径：总说只收结论，不讲机制；凡与前面章节连续十二字以上相同者改写。五栏之「禄」判完官不掌事，必须接下去说路走哪儿。九十块「落到你身上」凡只复述定盘卡、不添新柱位／新机制／新应期／新取舍者，一律重写。

### 1. 总说：八段压成六句

原八段里六段在复述机制（身强弱、用神、官星藏透、财食分量、关口），且第三段与禄栏连续二十九字相同：

> 官星这一头要说明白：官是丁火，只在戌、未里各藏一个，天干不透；时干癸是伤官，癸克丁，官既藏又受制。

改为六句结论，不再搬机制：

1. 一句话收这盘：身轻、财食重，是出力换钱的命，不是坐位子拿权的命。
2. 该使劲的地方只有一处——印与比：学历、资质、一门能换钱的专业身份、压得住阵脚的固定资产。往这上头加，一分力气见一分效。
3. 反过来，把力气押在职位、头衔、编制上，是拿最细的一条链去拉最重的车，越拉越空。
4. 贵气薄而不绝：名分、体面还留一线，实权没有；能当门面，不能当主路。
5. 要防三处：日支戌中戊土倒食，事情开头热、收尾散；年支子与时支未暗害，摩擦总在人后；丙子、壬午两步，是「再想靠名分」最容易撞墙的时候。
6. 四本对这组字的贵贱判断不齐，这份报告不抬不踩；哪一年动，是流年一层，此处不论。

### 2. 禄栏：三句往回收 → 四层接下去

原三句是「书里的好话都带着前提」「这条书上只有个方向」「具体到人还要看别的字」，判完官不掌事就收住，路走哪儿没交代。改为四层：

1. **走哪条路**：技艺（華蓋落戌未，取向「孤高藝術」，蔣本卷三）、私下经营（卷五「財庫居生地」，叁章校验表判条件成立）两类有原文旁证；文书、专业执照两类四本无专条，明写「不代书立论」。
2. **凭什么**：壬水食神在亥当令，直生年月甲乙之财，甲乙各有根，链条从月令通到年干、中间无字可断；官那条两头都断（不透干、被癸压）。庚金一点五分，克不动两位财。
3. **几时见分晓**：丁丑打底、庚辰为「路走通」的应期、辛巳收成；丙子、壬午是「再想靠名分」的关口。
4. **分寸**：丁藏戌未毕竟有火库为根，不是全无贵气，是贵气薄而不绝——薄在掌不了权，不绝在名分、体面、资质留一线。
