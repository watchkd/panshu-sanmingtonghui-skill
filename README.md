# 盘叔三命通会 · 四版并置的八字 skill 技能包

野生你盘叔的**盘叔三命通会**技能包：给一个四柱和性别，从万历本、蔣國祥本、辛丑本、四库本四个蒸馏包里现场检索相关原文，按层级摊开，再生成一份可打印的单文件 HTML 报告。

  <img src="报告/assets/赞赏码.jpg" width="180" alt="赞赏码">
</p>

如果觉得有用，欢迎赞赏支持；想交流命理，在本仓库开 issue 即可。

更多命理相关的 AI 技能与干货，见公众号「野生你盘叔」。

它不是排盘软件，也不是断命工具。它做的是三件事：**把四本书里跟这组字有关的段落捞出来、标明条件成立不成立、把原文译成人话并落到具体柱位**。判断的最终口径由读的人自己拿。

## 目录怎么排

```
辅助分析/                （仓库本体，约 1.1 MB，只有代码与文档）
├── SKILL.md              技能说明：口径、输出层级、报告结构与写作规范
├── 抽取层.py              四包解析层（读数据包、切卷篇、给记录编号）
├── 检索.py                检索层：四柱 → 分层证据 + 五栏简评，含自测
├── 构建数据包.py          把四版数据整理成可分发的 data/ 并打包、出清单
├── 输出模板.md            白话层与五栏的写法模板
├── 样例_白话/             两份白话层样例（甲子乙亥庚戌癸未、戊午四柱）
├── 自测/                  两份自测的输入输出与对比
└── 报告/
    ├── 生成报告.py         HTML 报告生成器（主报告 + 附录）
    ├── 证据_升级.json      逐条引文的条件校验结论
    ├── 白话_引文*.json     逐块白话文本（说明人话／落到你身上）
    ├── 修正清单.md         历次改稿记录与问题清单
    ├── assets/赞赏码.jpg   页尾赞赏码（生成时转 base64 内嵌）
    ├── 甲子乙亥庚戌癸未.html   成品：主报告
    └── 附录_神煞与命例.html    成品：附录（柒、捌两章）

data/                    （数据包，单独下载，约 19.3 MB / 287 个文件）
├── 万历/已校、万历/技能包、万历/原文
├── 蔣本/已校、蔣本/原文
├── 辛丑/包、辛丑/原文
├── 四库/五库、四库/原文
├── 索引/                 四柱索引 4,046 行、格名索引 1,528 行、两张归一表
```

**仓库本体不含数据。** 装好技能不等于能跑，还要把数据包放到 `data/`。


## 怎么跑

只依赖 Python 3（实测 3.12），无第三方库。中文参数在 Windows 下建议加 `-X utf8`。

```powershell
# 1) 检索：四柱 → 分层证据 + 五栏简评
python -X utf8 检索.py --四柱 "甲子 乙亥 庚戌 癸未" --性别 男
python -X utf8 检索.py --四柱 "戊午 戊午 戊午 戊午" --性别 男 --输出 报告.md

# 2) 自测：跑两份样例并写对比
python -X utf8 检索.py --自测

# 3) 生成 HTML 报告（在 报告/ 目录下运行；--输出 相对路径按当前目录解析）
cd 报告
python -X utf8 生成报告.py --四柱 "甲子 乙亥 庚戌 癸未" --性别 男 --生日 "1984-11-12 14:00" --输出 甲子乙亥庚戌癸未.html

# 不给生日也能出：大运只排干支，不推起运岁数
python -X utf8 生成报告.py --四柱 "戊午 戊午 戊午 戊午" --性别 男 --输出 戊午.html
```

生成器会写两个文件：主报告 `xxx.html` 与同目录的 `附录_神煞与命例.html`，两页互链。命令行的 `--输出` 只决定主报告文件名，附录固定叫 `附录_神煞与命例.html`。

**取数顺序**（[抽取层.py](抽取层.py) 第 12–58 行）：

1. 环境变量 `三命通会_数据`（或 `SANMING_DATA`）指向的目录；

3. 都没有 → 立刻退出（退出码 2），并打印数据包地址、应解压到哪、校验值。

不会静默降级，也不会出一份五个「无据」的空报告。

**装完自检**：`data/` 下必须是这五个目录 —— `万历`、`蔣本`、`辛丑`、`四库`、`索引`，外加 `数据清单.json`。对着 `数据清单.json` 核三样：文件数 287、各表行数（四柱索引合计 4,046、格名索引合计 1,528）、总字节 19,292,493。

```powershell
python -X utf8 检索.py --四柱 "甲子 乙亥 庚戌 癸未" --性别 男 --依据 --输出 依据.md
```

```
帮我装「盘叔三命通会」技能，四步：
1. 克隆 https://github.com/watchkd/panshu-sanmingtonghui-skill 到你存放技能的目录；
2. 下载数据包 https://github.com/watchkd/panshu-sanmingtonghui-skill/releases/download/data-v1.0.0/panshu-sanmingtonghui-data-v1.0.0.zip ；
3. 解压到技能目录下，使路径成为「技能目录/data」。解压后 data 下应有 万历、蔣本、辛丑、四库、索引 五个文件夹和一个 数据清单.json，缺一个就是没解压对；
4. 运行 python -X utf8 检索.py --四柱 "甲子 乙亥 庚戌 癸未" --性别 男 --依据，能列出五栏原文证据（带版本与卷次）就算装好；报错说「数据包缺失」就回到第 2 步。
```

- 蒸馏包是《三命通会》四底本的切篇结果：每包按卷、篇、段落编号，只读不写。
- 数据包里的原文正稿：万历（补脱后逐卷＋卷十二）、蔣國祥（38 块）、辛丑（2,030 页 OCR 正文合并为单文件）、四库（分卷）。校勘过程稿、页图、工作目录一律不进包。
- 报告里的逐条原文都带版本标（万历／蔣本／辛丑／四库）与卷篇位置；四本有异文与详略之别，同一断语未必四本俱全。
- `报告/assets/赞赏码.jpg` 是 520×520 的赞赏码原图，生成时转 base64 内嵌，因此主报告是单文件自包含（约 170KB，其中约 28KB 是这张图）。
- 起运与节气用内置的 Meeus 近似算法现算，不查表；误差在分钟级，够定月令与起运岁数，不用于择日。

## 已知边界

这些是不交给机器、也不该机器替你做的部分：

- **不排盘**。四柱要你自己给；本包只做检索与论述。时辰不准、闰月争议、真太阳时换算，都不在范围内。
- **不作品级**。上贵／中贵／常格这类判语，本包一律不出；四版对同一组字的贵贱判断不齐时，并列不择一，由读者自断。
- **不做流年细断**。逐运只给「喜／忌／半」与关口所在，哪一年动、动成什么样，属流年一层，报告明写「此处不论」。
- **不替代读书**。白话是译文，不是原文；凡推演处都标「据原局推」，与原文分段，二者不可混引。
- **结论不可跨命移植**。命例章里的断语附「不可移断」，同柱异命者不能拿别人的断语套本命。
- **索引与自测是中间产物**。`索引_按格名_*.csv`、`自测/` 用于查证与回归，不是交付内容；改了 `检索.py` 的口径要重跑 `--自测` 对比。
